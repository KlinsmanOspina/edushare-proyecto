# edushare-proyecto
# 🎓 EduShare: Plataforma Colaborativa Académica

Este proyecto es un prototipo funcional desarrollado para la materia de **Metodología de la Investigación**. Su objetivo es centralizar material de estudio por semestres y fomentar la colaboración mediante un sistema de validación social.

## 🚀 Funcionalidades
* **Repositorio Permanente:** Conexión con base de datos en la nube (Supabase).
* **Filtro por Semestre:** Organización dinámica de contenidos.
* **Control de Integridad:** Bloqueo automático de descargas en fechas de exámenes.
* **Estadísticas:** Análisis de impacto y ranking de colaboradores.

## 🛠️ Tecnologías
* **Lenguaje:** Python 3.x
* **Framework:** Streamlit
* **Base de Datos:** PostgreSQL (Supabase)
